# 复合因子前端适配与验收

## 范围

- 前端从 `main` 新建分支 `feature/factor-dependency-dag`。
- 适配后端同名分支，真实接口地址为 `http://8.137.157.152/api/v1`。
- 本轮未修改、部署后端，未合并主分支，未更新飞书文档。
- 已有 `dist` 和其他未提交文件保持原状；本轮构建输出至 `.tmp/factor-dependency-dag-build`。

## 实现

1. 因子编辑器新增源表因子、复合因子两种定义方式；复合因子不显示主表、JOIN、源表聚合及筛选配置。
2. 复合公式支持引用已发布因子版本、常量、四则运算、比较、一元运算、条件判断及受控函数；支持输出粒度、严格粒度对齐和总体值广播，除法显式配置零分母策略。
3. 复合因子沿用保存草稿、编译、推荐试算窗口、试算、发布流程，并可回显已有版本。
4. 因子运行参数读取编译产物；旧复合产物缺少继承参数时，沿冻结依赖读取上游产物并校验哈希，拒绝参数类型冲突。读取失败时阻止查询和试算，并提供重试。
5. 因子即时查询提交实际周期和运行参数，显示源库计算的结果及分组维度；不把即时查询当作发布前的异步试算凭据。
6. 因子编辑页接入上游完整依赖及下游影响分析，并支持跳转指定因子版本。
7. 普通指标编辑器使用后端能力预检返回的真实源因子配置物理字段映射；提交时保留上游源因子的映射，不再仅允许公式直接引用版本。
8. 已发布因子选择读取全部分页，避免第 100 条之后的新复合因子不可选。
9. 指标结果追溯支持按结果上下文逐层展开派生因子的上游；无匹配结果不伪造数据，切换上下文时忽略过期响应。
10. 修复公共 JSON 解析遗漏大整数数组的问题，防止不同版本 ID 被浮点取整成同一值；不改写 SQL 字符串、普通指标小数和科学记数法数值，兼容缺少 JSON reviver source context 的浏览器。

## 接口

新增前端接口封装：

- `GET /factor-versions/{id}/dependencies`
- `GET /factor-versions/{id}/dependency-graph`
- `GET /factor-versions/{id}/impact-analysis`
- `GET /analysis/results/{resultId}/factors/{factorResultId}/dependencies`

创建、编辑、编译、试算、发布和即时查询继续使用既有因子接口；指标能力预检继续使用 `POST /indicator-versions/drill-capabilities`。
