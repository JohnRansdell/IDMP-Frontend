# 指标分析查询模块隔离

## 原因与修复

顶部报告查询虽然已拆出界面，筛选条件仍通过父页面传给科室排名和下钻，趋势请求也合并了路由中的报告筛选。提交报告查询还会清空趋势筛选、重置下钻上下文。

- 顶部报告期、动态参数、路径和组合粒度筛选仅用于顶部查询。
- 趋势保留自己的月份范围与高级筛选；顶部自定义报告期不再初始化趋势范围。
- 科室排名和下钻独立选择统计周期，不继承顶部报告筛选。
- 区分报告路由变更与指标、版本及显式下钻入口变更；报告查询保留下钻层级和父节点。
- 静态指标的独立正式结果与顶部带筛选的即时结果分别读取。
- 后端账号数据权限不变，本次不修改指标配置或正式结果。

- 三个模块分别加载完成后修改顶部科室并查询，核对请求记录和模块内容均未发生变化；下钻在已进入科室层后验证，排名仍显示多个科室。
