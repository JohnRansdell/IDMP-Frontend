# 原子因子模板与字段选择验收

## 行为

- 因子模板仅用于原子因子，普通因子编辑仍支持复合因子。保存、复制版本、发布及实例化均拒绝复合模板；参数替换也不能绕过限制。
- 参数接口在 schema 的 `x-fieldOptions` 返回源表真实字段，复用因子编译器的主表、关联表解析。主表字段使用原字段引用，关联字段保留别名，避免同名歧义。
- 模板编辑中的字段默认值、可选字段及实例化页统一为字段选择；实例化候选遵守模板枚举与聚合字段类型限制。内部参数不展示、不提交覆盖。
- SQL 帮助按查询语句、统计查询、导入结果与指标公式、时间分组与下钻、可选业务参数组织。CTE 不再被描述为指标专属语法，删除依赖开发历史的提示。
