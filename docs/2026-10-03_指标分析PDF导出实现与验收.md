## 2. 导出范围与数据口径

指标分析页的“导出PDF”现在下载真实 PDF 文件，包含指标名称、指标和版本 ID、导出时间以及以下章节：

1. 查询条件和指标概览，包括当前分子、分母及展示值。
2. 当前时间粒度的趋势图和趋势表；如已有同级医院均值，也一并保留。
3. 当前已加载的科室排名。
4. 已加载的场景对比；没有正式场景结果时明确展示状态。
5. 计算公式、因子版本与正式分析快照等追溯信息。
6. 当前选中下钻页签时，附加当前已加载的下钻结果或因子追溯结果。

这是**页面已加载结果快照**，不是重新查询源库生成的审计报告。后端校验指标和已发布版本的归属，读取真实指标名，但不再次校验或计算请求中的每个结果值。PDF 会明确标注快照来源，不应作为服务端签名的数据证明。

导出点击时冻结数据和文件名，之后修改条件或切换指标不会改变正在导出的内容。未点击应用的趋势、组合粒度和场景条件不写入报告。即时查询的报告期和运行参数，与正式趋势及场景对比各自的时间范围分开标注，不暗示这些部分使用同一个筛选条件。

下钻仅导出当前已加载记录，不自动查询其他页，并注明已加载条数和总条数。超过 8 列时按字段组拆表，重复首列方便对应同一记录，不静默丢列。

## 3. 新增接口

`POST /api/v1/analysis/indicators/{indicatorId}/export/pdf`

请求类型：`application/json`。以下是最小可执行结构样例，实际页面会提交更多章节：

```json
{
  "indicatorVersionId": "102027642461313071",
  "metadata": [
    {"label": "报告期", "value": "2025-12-04 至 2026-02-12"},
    {"label": "结果来源", "value": "即时计算"},
    {"label": "运行参数", "value": "{\"patientName\":\"张\"}"}
  ],
  "sections": [
    {
      "title": "指标概览",
      "description": "即时查询已加载结果",
      "columns": ["项目", "结果"],
      "rows": [["指标值", "0.68%"], ["分子", "15"], ["分母", "2,207"]]
    }
  ]
}
```

字段说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `indicatorVersionId` | Long，前端用字符串保留精度 | 必填，必须是该指标的已发布版本 |
| `metadata` | 数组 | 必填，可为空；元素包含 `label` 和 `value` |
| `sections` | 数组 | 必填，至少一章；按提交顺序排版 |
| `sections[].title` | 字符串 | 必填，章节标题 |
| `sections[].description` | 字符串 | 可选，范围、状态等说明 |
| `sections[].columns` | 字符串数组 | 必填，表头，1 至 8 列 |
| `sections[].rows` | 二维字符串数组 | 必填，每行列数必须与表头相同；可为空 |
| `sections[].chartPng` | 字符串 | 可选，`data:image/png;base64,...`；只能是有效 PNG |

成功响应不是常规 JSON 包装：HTTP 200，二进制 `application/pdf`，`Content-Disposition: attachment`，`Cache-Control: no-store`。

参数错误返回现有格式的 JSON 错误响应，包含中文错误消息及 traceId；无效指标或版本返回 404。网关拒绝超大请求可能返回 HTML 和 413，前端同样转为“导出内容过大，请缩小分析时间范围后重试”。

限制：请求体最多 4,000,000 字节，最多 30 项元数据、12 章、累计 3000 行、250000 个文本字符。标题和表头最长 128 字符，正文单项最长 2048 字符。单张图片编码最多 1500000 字符，总图片编码最多 3000000 字符；尺寸不超过 2400×1600，且不超过 400 万像素。报告最多 100 页。网关已有请求体限制仍然生效，可能比应用限制更小。

前端导出超时为 60 秒，支持现有登录恢复；失败时不下载错误 JSON 或无效文件。连续点击不会重复导出，也不会清空正常查询缓存。

## 4. 实现说明

- 后端使用 OpenPDF 1.3.43，应用层做校验，基础设施层负责排版，Web 层提供二进制下载。
- 内置 Apache 2.0 许可的 Droid 中文字体，不依赖服务器临时安装字体；中文文本可以搜索和复制。
- 前端使用当前 ECharts 配置生成白底 PNG，禁用导出图表动画，生成后释放图表实例。
- PDF 表格自动分页并重复表头，长文本换行；章节标题与表格之间保留足够间距。
- 不新增数据库表，不保存 PDF，不修改指标或计算结果，不触发计算批次。
