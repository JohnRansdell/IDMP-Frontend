# 2026-10-20 看板性能优化与回归

## 实现

- 看板查询与组件预览请求 COLUMNAR，统一解码还原原 WidgetResult；共享数据集仅还原一次，保留全部行和下钻上下文。
- 服务端结果为只读行数组，运行态结果容器使用 shallowRef，避免对每个明细单元格创建 Vue 深层代理。
- 同一行数组的字段对齐、报告期规范化与科室名称处理复用结果；新查询替换行数组时自动失效。
- 分类分组用 WeakMap 共享，只按分类解析显示名；排序、度量和零值过滤仍按组件独立计算。本地可编辑数组不缓存。
- 未改变计算口径，未添加表格分页，未修改组合成员筛选规则。

## 实际数据验证

只读捕获质量安全看板 2026 年 3 月响应，12 个组件，最大数据集 6,567 行。原响应、Java 编码后响应、前端解码结果逐组件逐行完全一致，实际绑定显示模型与远程主分支实现一致。

| 项目 | 原实现 | 新实现 |
| --- | --- | --- |
| 同一响应 JSON 字节（COMPACT 对 COLUMNAR） | 9,915,031 | 2,394,631 |
| 同一响应 gzip 字节 | 1,119,828 | 780,675 |
| 解析及还原中位耗时 | 206.76 ms | 155.66 ms |
| 响应式数组分组对首次新分组 | 766.89 ms | 6.79 ms |
| 相同数据后续组件共享分组 | 原实现重新分组 | 0.63 ms |

数据为本机 7 次代码基准中位数，JSON/gzip 是同一响应离线重编码后的大小，不是线上整页或网络压测。真实响应和截图只在 `.tmp` 本地保存，不提交业务数据。

真实 BindingWidget 挂载检查：图表非空、表格 53 行；切换科室后表格 1 行，恢复后 53 行；桌面及 390px 窄屏无横向溢出、无组件异常。该验证是本地捕获数据，不等于新后端已部署或线上端到端通过。

最终前端全套 636 项通过，生产构建通过；后端看板相关 42 项通过，1 项可选捕获测试默认跳过，该项在传入真实本地响应时已单独通过。

## 复跑

```powershell
npm test
npx vite build --outDir .tmp/dashboard-build
node test/dashboard-performance.bench.mjs .tmp/dashboard-live/encoded.json .tmp/dashboard-live/definition.json .tmp/dashboard-live/full.json
```

`test/dashboard-performance.capture.mjs` 只读获取看板定义与 FULL 响应；后端 `DashboardCapturedResponseTests` 通过 `idmp.dashboard.live-input`、`idmp.dashboard.live-output` 指定捕获输入和编码输出。合成 10,000 行契约样本由后端测试的 `idmp.dashboard.fixture` 生成，与真实样本分开统计。
