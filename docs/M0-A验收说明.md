# IDMP M0-A 验收说明

## 已完成

- 来源元数据、数据域、语义表、语义字段和因子级联页面已接入正式 M0 接口。
- 路由具备查看/创建/同步/字段编辑权限码占位，兼容后端尚未返回完整权限集合的情况。
- 请求层保留 BIGINT 字符串解析，统一携带 HTTP 状态、业务 code 和 traceId；401 进入登录占位流程。
- 查询请求使用版本号忽略过期响应，写操作使用 loading 防重复提交。
- `pnpm.cmd test`：3 项 Node 内置测试通过。
- `pnpm.cmd run build:prod`：生产构建通过。

## 端到端验收路径

在连接当前实现后端后，按以下顺序执行：来源同步 → 查看源表 → 创建数据域 → 创建语义表 → 映射字段 → 配置默认时间字段 → 因子编辑器选择数据域/语义表/字段。

## 当前阻塞

- 未提供完整权限集合和正式登录接口，当前为权限元数据占位与登录占位页。
- 未提供 CODE/值集查询接口，页面不伪造值集选项。
- 未提供因子试算接口，周期参数校验仅做前端门禁。
- 当前环境没有浏览器自动化依赖和可连接后端，Chrome/Edge 1366×768、1920×1080 视觉及真实端到端链路需联调环境补验。
