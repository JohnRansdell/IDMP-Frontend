# IDMP 医疗质量指标数据管理平台前端

IDMP Frontend 是医疗质量指标数据管理平台的 Web 前端，用于数据资产配置、因子与指标生命周期管理、场景配置、计算任务跟踪、指标分析和结果下钻。

项目基于 Vue 3 和 Vite，当前定位为可连接真实后端的联调与演示版本。核心纵向链路已有页面和接口基础，但浏览器端到端验收、完整权限治理以及部分业务模块仍在建设中，不应视为生产验收完成。

## 技术栈

- Vue 3.5
- Vue Router 4.6
- Element Plus 2.13
- ECharts 5.6
- Vite 6.4
- pnpm
- JavaScript 与 Vue 单文件组件

## 快速开始

要求：使用项目声明的 pnpm 版本，并准备兼容当前 Vite 版本的 Node.js 环境。

```powershell
pnpm install
pnpm dev
```

开发服务启动后访问：

```text
http://localhost:5173
```

常用命令：

```powershell
# 运行 Node 自动化测试
pnpm test

# 生成生产构建
pnpm run build:prod

# 本地预览生产构建
pnpm preview
```

## API 配置

前端默认使用同源 API 前缀：

```text
/api/v1
```

如需覆盖，可在本地环境文件中配置 `VITE_API_BASE_URL`。仓库中只应保存不含真实地址的示例：

```dotenv
VITE_API_BASE_URL=/api/v1
```

推荐由网关或反向代理将 `/api/v1` 转发到后端服务。不要把内网 IP、正式域名、端口、账号、令牌或 Cookie 写入源码、README、提交记录和构建产物。

## 当前能力

### 数据资产与标准化

- 来源元数据同步、源表与物理字段查询。
- 数据域、语义表和语义字段配置。
- 默认时间字段及字段业务角色维护。
- 值集、值集版本和值项生命周期管理。
- 语义字段值集绑定、源值画像及转换规则配置。

主要入口：

- `/data/sources`
- `/data/domains`
- `/data/value-sets`

### 因子与因子模板

- 因子目录、详情和版本查询。
- 因子 DSL 配置、编译、试算、结果读取和发布。
- 删除影响检查、软删除、回收站和恢复。
- 因子模板目录、版本、校验、发布和模板实例化。

主要入口：

- `/factor`
- `/factor/templates`
- `/factor/recycle-bin`

### 指标管理

- 指标目录、筛选、表格与卡片视图。
- 指标、指标版本及公式生命周期。
- 公式编译、试算、发布和正式计算入口。
- 下钻能力预检、路径和最大层级配置。
- 删除影响检查、软删除、回收站和恢复。
- 指标目录和详情中的已发布场景引用统计。

主要入口：

- `/indicator`
- `/indicator/edit/:id?`
- `/indicator/view/:id`
- `/indicator/recycle-bin`

### 场景管理

- 场景及场景版本管理。
- 指标版本集合和覆盖规则配置。
- 合并预览、校验、发布及乐观锁处理。

主要入口：

- `/scenarios`
- `/scenarios/:scenarioId/edit`

### 计算、分析与下钻

- 计算批次创建、异步任务查询和批次详情。
- 批次取消及失败节点重试。
- 看板定义和数据查询。
- 指标趋势、维度结果和正式结果入口。
- 组织、病种等路径下钻以及因子结果追溯。

主要入口：

- `/calc`
- `/dashboard`
- `/analysis`
- `/analysis/drill`

### 认证与系统管理

- 用户名和密码登录。
- Bearer Access Token 请求认证。
- 当前用户上下文恢复。
- Refresh Cookie 与 CSRF Token 刷新流程。
- 并发 401 单次刷新及原请求重试。
- 当前会话退出和全部会话退出。
- 用户列表查询和角色创建。

主要入口：

- `/login`
- `/system`

## 数据来源与演示降级

部分页面同时支持真实接口和演示数据。页面会标识当前数据来源；演示值只用于展示界面结构，不代表正式计算结果，也不能作为验收证据。

- 看板优先读取已发布看板和正式查询结果；接口不可用时可显示明确标识的演示看板。
- 指标和因子目录在接口不可用时可能显示明确标识的演示目录。
- 指标分析中的部分趋势或排名仍可能使用本地展示配置。
- 指标映射和预警中心目前主要是界面演示，操作不会形成完整后端业务闭环。

正式验收必须使用同一部署版本的真实接口和测试数据，从页面完成对象创建、计算、结果查询及下钻，不得依赖固定 ID、Mock 数据或手工拼接上下文。

## 安全与脱敏要求

仓库及其文档不得包含以下内容：

- 内网或公网真实 IP、域名、端口和服务拓扑。
- 本机绝对目录、服务器目录、共享盘路径和部署账号。
- 用户名、密码、Access Token、Refresh Token、Cookie、密钥或连接串。
- 患者、医务人员或其他自然人的身份信息和业务明细。
- 可定位真实联调环境的资源 ID、批次 ID、对象数量、日志或截图。
- 未经脱敏的数据库表样例、请求响应、错误堆栈和追踪信息。

提交日志、Issue、演示截图和测试附件也应遵守同一规则。示例统一使用语义化占位符或本地同源地址；敏感配置通过受控环境变量或密钥管理服务提供。

## 当前边界

- 通用公式 AST 编辑器仍以简单比率场景为主。
- 场景批量计算、场景结果和跨场景对比尚未形成完整闭环。
- 数据采集、完整清洗转换和独立数据质量模块尚未完整交付。
- 看板布局仍主要保存在浏览器本地，服务端持久化待完善。
- 报表、文件导出和正式预警通知尚未完成。
- 菜单、路由、按钮、字段和数据范围权限尚未形成完整联调闭环。
- 患者或记录级下钻仍需完善访问目的、脱敏、数据范围和审计控制。
- 当前自动化测试以适配器和数据契约为主，尚不能替代浏览器 E2E、性能、安全和生产部署验收。

## 构建与部署原则

1. 在受控 CI 或构建环境执行测试和生产构建。
2. 将完整 `dist` 作为同一版本制品发布，不要混用不同构建生成的哈希资源。
3. 使用环境配置或网关提供后端地址，不在前端制品中固化真实服务地址。
4. 部署前核对前端提交、后端版本、数据库迁移和配置清单。
5. 正式环境关闭或严格标识演示降级，并完成权限、安全和审计验收。
