# 因子查看与编辑分离

- 新增 `/factor/view/:id`，展示基本信息、运行参数与即时查询、因子依赖关系三个部分，不显示定义编辑、保存、编译、试算、发布按钮。
- 因子目录的名称和“查看”打开详情；“编辑”仍进入原编辑页。详情页的“编辑因子”携带当前版本进入编辑页。
- 默认查看当前发布版本；没有发布版本时选择最新版本。支持显式版本参数 `factorVersionId` 和页面版本切换；版本归属不匹配时禁止展示定义和执行查询。
- 运行参数复用既有编译产物、复合因子上游参数继承、参数校验及查询接口。静态版本不传周期；时序版本优先显示推荐周期，推荐失败允许手动选择。未编译版本显示说明，不自动编译。
- 即时查询只影响本次参数，不保存因子，不创建试算或发布任务。参数或版本改变后清空旧结果，并忽略过期返回。
- 依赖面板复用既有依赖图/影响分析接口；依赖、结果追溯、指标公式中的“查看因子”统一进入详情页。
- 不修改后端，也不改变原因子编辑页的定义配置与发布流程。

验证：新增 9 项版本选择、归属校验、静态/时序查询、参数继承、失败重试及过期请求测试；全量回归 597 项通过。本地 Chrome 模拟接口验证目录名称/查看/编辑入口、版本切换、参数查询、依赖跳转及手机布局，不向真实后端写入。

浏览器证据：`.tmp/factor-detail-browser/result.json`、`desktop.png`、`mobile.png`。

构建输出：`.tmp/factor-detail-build`，不覆盖既有 `dist`。

重跑：`npm run test:factor-detail`、`npm run test:e2e:factor-detail`、`npm run build:prod -- --outDir .tmp/factor-detail-build`。

## 基本信息排版优化

参考指标查看页的字段卡片样式，将基本信息按因子资料、计算配置、版本信息分组；组间加分隔线，字段使用浅色背景和独立边框，因子说明单独展示。编码及 ID 使用等宽字体，版本状态使用统一状态标记。桌面四列、中等屏幕两列、手机单列，长文本与 ID 自动换行。版本选择、运行参数与即时查询、依赖关系仍使用现有逻辑。

排版构建输出：`.tmp/factor-detail-layout-build`。截图继续使用 `.tmp/factor-detail-browser/desktop.png` 与 `mobile.png`。
