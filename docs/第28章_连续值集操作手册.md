# 第 28 章：连续值集 → 连续范围过滤因子操作手册

本文档面向 IDMP 前端操作人员，按当前页面已实现能力编写，对齐《IDMP 当前实现接口文档与测试样例（基于方案 revision 1047）0826.md》第 28 章。

本文要完成的业务目标是：为本次验收创建一套隔离的语义表、语义字段、连续值集和因子；连续值集声明住院总费用的金额单位、精度和合法边界，并绑定到本次新建的 `TOTAL_COST` 语义字段；最后统计试算周期内 `1000.00 <= TOTAL_COST < 5000.00` 的记录数，完成编译、试算和发布。

> 重要：连续值集不维护“1000–5000 元”这样的枚举档位。连续值集只约束字段的单位、精度、合法取值范围；实际筛选区间在因子编辑页面填写。

## 1. 开始前检查

### 1.1 登录和权限

登录 IDMP 后，左侧菜单应能看到：

- 数据治理 → 数据域管理、值集管理；
- 因子管理。

如果菜单不可见、按钮显示无权限，联系管理员授予值集、语义字段和因子管理权限后再继续。

### 1.2 隔离原则：不要修改已有验收对象

每次执行本手册都必须使用新的批次后缀，不得给已有 `TOTAL_COST` 重新绑定值集，也不得复用旧值集或旧因子编码。这样可以避免覆盖既有绑定、触发资源版本冲突或污染其他人的验收结果。

本手册只复用以下只读来源：

- 已同步物理源表 `vmq_basicinformationba`；
- 真实源字段 `total_cost` 和 `out_date`；
- 源表中的真实数据记录。

其余业务对象尽可能全部新建：数据域、语义表、两个语义字段及映射、连续值集、范围因子和基线因子。

> 当前前端可创建数据域，但“数据域校验发布”尚未接入。如果新建数据域保持 `DRAFT`，因子创建页不会列出它。推荐由管理员先为本次验收准备并发布一个带唯一后缀的空数据域；或者在创建后由后端/管理员完成发布。不要因为新数据域暂不可选，就回到已有语义字段上重复绑定。

### 1.3 确定本次唯一测试标识

开始操作前先确定一个只属于本次验收的测试标识。建议采用 `TEST_年月日_两位序号` 的格式，例如：

```text
TEST_20260827_01
```

以下步骤统一使用 `TEST_20260827_01` 作为可以直接输入的完整示例，不再使用带大括号的占位符。如果该标识已经被使用，将末尾序号改为 `02`、`03` 等，并让本次所有新建对象使用相同日期和序号。

|本次新建对象|直接输入的测试编码或名称|说明|
|---|---|---|
|数据域|`TEST_CONT_COST_20260827_01`|本次测试专用数据域|
|语义表|`TEST_INPATIENT_COST_20260827_01`|本次测试专用语义表|
|费用语义字段|`TOTAL_COST`|属于本次新语义表，不复用旧字段 ID|
|时间语义字段|`DISCHARGE_TIME`|属于本次新语义表，不复用旧字段 ID|
|连续值集|`TEST_VS_CONT_COST_20260827_01`|本次测试专用值集|
|范围因子|`TEST_F_CONT_COST_1000_5000_20260827_01`|本次测试专用范围因子|
|基线因子|`TEST_F_CONT_COST_BASE_20260827_01`|本次测试专用基线因子|

若任一编码提示已存在，说明 `TEST_20260827_01` 已经被使用。不要打开旧对象继续修改；例如将本次标识改为 `TEST_20260827_02`，并从数据域开始统一使用新序号重新创建。

### 1.4 推荐的验收参数

|项目|输入或期望值|
|---|---|
|值类型|`DECIMAL`|
|单位|`CNY`|
|精度 / 小数位|18 / 2|
|合法范围|`0.00` 至 `100000000.00`|
|费用范围|开始 `1000.00`，结束 `5000.00`|
|建议试算周期|优先使用编译后后端推荐周期|

范围按左闭右开区间执行，即包含 1000.00，不包含 5000.00。

## 2. 创建本次隔离的数据模型

### 2.1 创建新的数据域

如果管理员已经为本次准备并发布了空数据域，确认其编码为 `TEST_CONT_COST_20260827_01` 后直接进入 2.2。否则：

1. 点击左侧“数据治理 → 数据域管理”。
2. 点击右上角“新建数据域”。
3. 数据域编码输入 `TEST_CONT_COST_20260827_01`。
4. 数据域名称输入“连续费用测试_20260827_01”。
5. 说明输入“第28章连续值集隔离测试，仅供 TEST_20260827_01 使用”。
6. 点击“确认创建”，在二次确认框中再次点击“确认创建”。
7. 创建后进入该数据域工作台。

新建数据域初始状态通常为 `DRAFT`。继续配置不影响已有数据域；但在进入第 6 章创建因子前，必须由管理员或后端将该数据域发布，否则因子页面不会显示它。

> 必做项：数据域刚创建时还没有可选的默认时间字段。完成 2.2 至 2.4 的语义表和 `DISCHARGE_TIME` 字段映射后，必须在工作台底部的“默认时间字段”选择 `DISCHARGE_TIME` 并点击“保存默认时间字段”。不设置时，因子页面会显示“当前语义表未配置”，无法使用统计周期试算。

### 2.2 新建语义表

1. 在本次新数据域工作台的“语义表”区域点击“新建语义表”。
2. “来源物理表”选择已同步的 `vmq_basicinformationba`。该动作只复用真实源数据，不修改物理表。
3. “语义表编码”输入 `TEST_INPATIENT_COST_20260827_01`。
4. “语义表名称”输入“住院费用测试表_20260827_01”。
5. 点击“确认创建”，在二次确认框确认来源表和新语义表编码后继续。
6. 创建成功后点击该语义表所在行，使“当前语义表上下文”显示本次新编码。

### 2.3 新建费用语义字段映射

1. 在左侧“来源字段”中搜索 `total_cost`，点击该行。
2. 在下方“新增或更新映射”确认来源字段为 `total_cost`。
3. 标准字段编码输入 `TOTAL_COST`。
4. 业务名称输入“测试住院总费用_20260827_01”。
5. 标准数据类型选择“小数（DECIMAL）”。
6. 业务角色选择“度量（数值聚合）”。
7. 敏感信息保持“否”。
8. 点击“保存字段映射”。

成功后，右侧“标准业务字段”会出现本次语义表下的新 `TOTAL_COST`。虽然字段编码与旧模型相同，但字段 ID 和所属语义表都是新建的，不会改变旧字段绑定。

### 2.4 新建时间语义字段映射

1. 在左侧“来源字段”中搜索 `out_date`，点击该行。
2. 标准字段编码输入 `DISCHARGE_TIME`。
3. 业务名称输入“测试出院时间_20260827_01”。
4. 标准数据类型选择“日期时间（DATETIME）”。
5. 业务角色选择“维度（筛选、分组、值集）”。
6. 敏感信息保持“否”。
7. 点击“保存字段映射”。
8. 滚动到工作台底部“默认时间字段”区域，选择 `DISCHARGE_TIME（测试出院时间_20260827_01）`。
9. 点击“保存默认时间字段”；成功后页面提示保存成功，语义表列表的“默认时间字段”列显示 `DISCHARGE_TIME`。

### 2.5 查看本次 TOTAL_COST 的真实字段画像

1. 确认当前语义表仍为 `TEST_INPATIENT_COST_20260827_01`。
2. 在右侧“标准业务字段”搜索 `TOTAL_COST`。
3. 在本次新字段所在行点击“字段画像”。
4. 弹窗中查看总记录数、空值数和不同值；若后端返回离散值明细，还会显示源值、记录数和占比。
5. 关闭弹窗返回工作台。

预期交互：点击后先显示“正在读取源字段画像”，成功后显示真实 `total_cost` 的统计结果。第 28 章原始实测为总记录数 95,755、空值数 0；当前环境数据变化时以实际结果为准。

如果提示“字段画像读取失败”，检查当前点击的是本批次新语义表下的 `TOTAL_COST`，且该行已有来源字段映射 ID；不要转到旧数据域重新绑定。

## 3. 创建住院总费用连续值集

### 3.1 进入创建页面

1. 点击左侧“数据治理 → 值集管理”。
2. 在页面右上角点击“新建值集”，进入独立的“新建值集”页面。
3. 在“基础信息”中填写编码、名称、值类型、来源标准名称和说明。
4. 在“数据组织方式”中点击“连续数值/日期”卡片。页面会自动使用接口匹配模式 `CONTINUOUS` 并展开“连续范围规范”。
5. 在“连续范围规范”中依次填写下表内容。

|页面字段|输入值|说明|
|---|---|---|
|编码|`TEST_VS_CONT_COST_20260827_01`|可以直接输入；必须是本次测试的新编码|
|名称|测试住院总费用连续值集_20260827_01|用于区分本次测试对象|
|数据组织方式|连续数值/日期|点击后立即展开“连续范围规范”，接口匹配模式为 `CONTINUOUS`|
|值类型|小数|对应 `DECIMAL`|
|来源标准名称|`vmq_basicinformationba.total_cost`|建议填写，便于追溯来源字段|
|单位|`CNY`|金额单位|
|总精度|`18`|最大有效数字位数|
|小数位|`2`|金额保留两位小数|
|最小值|`0.00`|允许的最小合法费用|
|最大值|`100000000.00`|允许的最大合法费用|
|说明|第28章连续费用测试 TEST_20260827_01；真实住院总费用的单位、精度与合法范围|保留测试标识，便于后续清理|

精确枚举、前缀编码、区间档位和层级目录都是值项型值集；它们创建后进入版本页维护值项。“连续数值/日期”不维护值项，因此在当前页面填写连续范围规范。

日期/日期时间连续值集与金额操作相同，但“时间粒度”和“时区”可按需要填写，例如 `DAY`、`Asia/Shanghai`；整数连续值集的小数位必须为 0。

### 3.2 创建后的页面反馈

1. 点击页面底部“创建连续值集并继续”。
2. 前端会先检查编码、名称以及连续规范的精度配置：
   - 总精度必须是 1 至 38 的整数；
   - 小数位必须介于 0 和总精度之间；
   - INTEGER 类型的小数位必须为 0；
   - 连续值集必须填写单位。
3. 校验通过后，页面调用 `POST /api/v1/meta/value-sets`。
4. 成功时会弹出“值集 … 创建成功”。若接口返回 V1 版本 ID，页面直接进入 V1 版本编辑页；若未返回版本 ID，则进入值集详情页。

此时预期状态：

- 值集主记录为 `DRAFT`；
- 自动生成 V1 草稿版本；
- 版本编辑页或详情页显示“连续值规范”，而不是“值项”；
- 不会出现新增、删除或保存枚举值项的操作。

如果后端返回编码已存在，说明 `TEST_20260827_01` 已被使用。不要打开同编码旧值集继续修改；将序号改为 `02` 后，后续值集和因子也必须使用相同的新序号。

## 4. 校验并发布连续值集版本

### 4.1 打开版本编辑页

1. 创建成功后通常会直接进入“值集版本 V1”页面。
2. 如果当前停留在值集详情页，则在“版本历史”区域选中 V1，再点击“编辑版本”。
3. 在版本编辑页确认摘要中的：
   - 匹配模式为“连续范围匹配”；
   - 值类型为“小数”；
   - 连续规范中的单位、精度、最小值、最大值与创建时输入一致。

### 4.2 如需修改连续规范

仅草稿或已校验版本可编辑。

1. 在“连续值规范”表单中修改单位、精度、小数位、边界或日期时间语义。
2. 点击“保存连续值规范”。
3. 成功后页面提示“连续值规范已保存，请重新校验版本”。

注意：该动作调用 `PATCH /api/v1/meta/value-set-versions/{versionId}` 并携带 `continuousSpec`。如果服务端尚未支持 PATCH 更新 `continuousSpec`，页面会提示保存失败；此时请保持创建时的规范不变，或由后端补齐接口后再编辑。

### 4.3 校验与发布

1. 在“版本状态操作”区域点击“校验版本”。
2. 成功时会出现“值集版本校验通过”，校验结果框显示 `valid=true`，并可能更新资源版本号。
3. 点击“发布版本”。
4. 在确认对话框中点击确认。

预期交互：

- 发布成功后提示“值集版本发布成功”；
- 当前版本状态变为 `PUBLISHED`；
- 值集详情页中的“当前发布版本”更新为该版本 ID；
- 连续值集全程不会调用 `PUT /value-set-versions/{versionId}/items`。

### 4.4 后续改版

若已发布版本需要调整：

1. 回到值集详情页。
2. 点击“复制为新版本”。
3. 页面调用 `POST /api/v1/meta/value-sets/{valueSetId}/versions`，以当前选择版本作为 `copyFromVersionId`。
4. 成功后自动打开新草稿版本；修改规范、校验、发布即可。

不要尝试直接修改已发布版本；应始终复制为新版本后再发布。

## 5. 将连续值集绑定到本批次新建的 TOTAL_COST

### 5.1 进入字段绑定窗口

1. 返回“数据治理 → 数据域管理”。
2. 进入本次新建并已发布的 `TEST_CONT_COST_20260827_01` 工作台。
3. 点击本次语义表 `TEST_INPATIENT_COST_20260827_01`。
4. 在右侧“标准业务字段”中找到 `TOTAL_COST`，并确认业务名称为“测试住院总费用_20260827_01”、来源字段为 `total_cost`。
5. 点击该行操作列的“绑定值集”。

页面会打开“绑定语义字段值集”弹窗，并并行读取：

- 当前字段的既有绑定；
- 已发布值集列表。

### 5.2 选择并确认绑定

1. 先查看“当前绑定”。本批次新建字段应显示未绑定；如果已经显示其他值集，立即关闭弹窗，说明选错了语义表或字段，禁止覆盖原绑定。
2. 在“选择已发布值集”中输入或选择本次新建的 `TEST_VS_CONT_COST_20260827_01`，同时核对名称中的测试日期和序号。
3. 选择后，前端会读取该值集的当前发布版本，检查：
   - 匹配模式是否为 `CONTINUOUS`；
   - 值类型是否与 `TOTAL_COST` 的 `DECIMAL` 一致；
   - CONTINUOUS 是否绑定在 INTEGER、DECIMAL、DATE、DATETIME 字段上。
4. 校验通过后，点击“确认绑定”。

预期交互：

- 成功提示“值集绑定成功”；
- 窗口关闭，字段列表重新加载；
- 后端绑定结果应包含 `bound=true` 和当前发布 `valueSetVersionId`。

常见提示及处理：

|现象|原因与处理|
|---|---|
|选择后自动清空，并提示类型不一致|选择了 STRING/INTEGER 等与字段类型不同的值集版本；改选 DECIMAL 连续值集|
|提示连续值集仅可绑定数值、日期或日期时间字段|字段类型不满足 CONTINUOUS 要求；检查语义字段映射|
|提示绑定失败或字段不是 DIMENSION|接口文档 2.12 的旧约束与第 28 章实测能力存在冲突。第 28 章已实测 MEASURE 的 TOTAL_COST 可绑定 CONTINUOUS；请让后端以实际服务契约核对该限制|
|提示 resourceVersion 冲突|关闭窗口后重新打开，读取最新字段资源版本再绑定|
|弹窗一打开就显示已有绑定|当前字段不是本次测试的新字段；关闭弹窗，重新核对数据域、语义表、业务名称和 `TEST_20260827_01`，不要覆盖|

## 6. 创建连续范围过滤因子

### 6.1 新建因子并填写基础信息

1. 点击左侧“因子管理”。
2. 点击右上角“新建因子”。
3. 在“1 基础信息”填写：

|字段|输入值|
|---|---|
|因子编码|`TEST_F_CONT_COST_1000_5000_20260827_01`|
|因子名称|测试住院总费用1000至5000元记录数_20260827_01|
|业务分类|`E2E`|
|说明|真实费用范围过滤：1000.00 <= total_cost < 5000.00|

### 6.2 选择数据域和语义表

1. 在“2 计算口径配置”中，数据域选择本次的 `TEST_CONT_COST_20260827_01`。
2. 语义表选择本次的 `TEST_INPATIENT_COST_20260827_01`。
3. 页面会读取该表字段，并显示“统计周期字段”。确认显示为 `DISCHARGE_TIME`。

如果数据域下拉框没有本批次数据域，通常是因为新数据域仍为 `DRAFT`。请让管理员或后端完成发布后刷新页面；不要改选一个已有数据域继续操作。如果显示“当前语义表未配置”，先返回本批次数据域工作台，为该语义表配置默认时间字段；否则试算周期无法正常使用。

### 6.3 选择统计方式

1. 在“3 统计方式”点击“记录计数”。
2. “计数字段”保持不选，表示 `COUNT(*)`。
3. “分组维度”保持不选，表示返回总体记录数。

页面“当前口径”会随选择实时更新，此时应表达为对当前语义表全部记录做计数，等待配置筛选范围。

### 6.4 添加试算周期条件

1. 在“4 筛选范围”选择“显式筛选条件”。
2. 点击“+ 添加筛选条件”。
3. 在第一个条件的字段下拉框中选择 `DISCHARGE_TIME`。
4. 判断方式自动选中“使用试算周期”。
5. 值输入框显示“由下方‘本次试算周期’自动传入”，无需填写。

此条件保存到 DSL 后是：

```json
{
  "nodeType": "PREDICATE",
  "fieldCode": "DISCHARGE_TIME",
  "operator": "BETWEEN",
  "parameter": "period"
}
```

### 6.5 添加费用连续范围条件

1. 再点击“+ 添加筛选条件”。
2. 在第二个条件的字段下拉框中选择 `TOTAL_COST`。
3. 判断方式自动选中“位于连续范围”。
4. 在“开始值”输入 `1000.00`。
5. 在“结束值”输入 `5000.00`。
6. 查看输入框下方提示，应显示单位、合法范围、小数位和 `[开始值, 结束值)` 语义。

页面会自动：

- 保留 `TOTAL_COST` 的数值字段能力，不把它当作枚举维度；
- 读取其当前绑定的已发布连续值集版本；
- 在保存 DSL 时写入该版本 ID；
- 不为该条件写入 `parameter=period`。

点击“查看技术配置”可检查 DSL。费用条件应类似：

```json
{
  "nodeType": "PREDICATE",
  "fieldCode": "TOTAL_COST",
  "operator": "BETWEEN",
  "valueSetVersionId": "实际发布版本ID",
  "value": {
    "start": "1000.00",
    "end": "5000.00"
  }
}
```

不要手工修改版本 ID；前端会使用字段当前绑定值集的已发布版本。

### 6.6 前端校验说明

点击“保存因子定义”或“保存草稿并继续”时，前端会拦截以下情况：

|提示|处理|
|---|---|
|请填写连续范围的开始值和结束值|两个输入框都必须填写|
|连续范围的开始值必须小于结束值|确保开始小于结束|
|连续数值范围必须为合法数字|删除中文字符、千分位逗号等非数字内容|
|小数位不能超过值集定义的 2 位|例如 1000.001 不合法；改为 1000.00|
|开始值不能小于 0.00 / 结束值不能大于 100000000.00|改回连续规范定义的合法边界内|

通过校验后，点击“保存草稿并继续”。页面提示因子草稿已保存，并显示因子 ID、版本 ID 和草稿状态。

## 7. 编译、试算、查看结果和发布

### 7.1 编译因子

1. 保存成功后，页面显示“编译、试算与发布”区域。
2. 点击“编译并校验”。
3. 成功时页面显示“编译校验通过”和编译产物 ID，随后自动读取后端推荐试算周期。

自动推荐期间，试算周期卡片显示“正在获取后端推荐周期”；该探测不会创建计算任务。推荐成功时，日期控件会自动填入推荐的 `[recommendedPeriodStart, recommendedPeriodEnd)`，并显示“后端推荐”、数据覆盖范围和预计匹配记录数。

如编译失败，页面会显示后端诊断；当诊断路径涉及 `value.start`、`value.end`、`valueSetVersionId` 或 continuous 字段时，前端会标记为“连续范围条件 …”，便于定位回费用范围输入。

### 7.2 发起试算

1. 编译后无需先点击日期控件。若页面已显示“后端推荐”，直接点击“试算并查看结果”，前端会将推荐开始、结束时间原样传给试算接口。
2. 如需自定义验证范围，直接在“本次试算周期”日期控件中修改开始和结束时间；标签会变为“用户自定义”，试算时优先使用该周期。
3. 如果修改后需要恢复后端建议，点击“恢复推荐周期”。
4. 若推荐接口返回无匹配数据或请求失败，页面会给出提示；此时仍可手动选择完整周期后点击“试算并查看结果”。
5. 页面提交异步任务后显示任务 ID、批次 ID 和任务状态；状态尚未结束时，可点击“刷新状态”。
6. 任务成功后，前端自动读取结果。

第 28 章验收样例的期望结果：

|结果字段|期望值|
|---|---|
|范围因子来源记录数|18,700|
|结果值|18,700.00000000|
|来源数据状态|`HAS_DATA`|
|计算结果|`CALCULATED`|
|质量状态|`PASSED`|

前端已兼容第 28 章 `targets[].resultSets[].results[]` 的返回结构。若实际源库或试算周期不同，记录数会不同；应以“范围因子结果小于无费用范围基线、质量状态正常”为主进行验收。

### 7.3 发布因子

1. 确认编译和试算结果符合预期。
2. 点击“发布因子版本”。
3. 在确认框中点击确认。
4. 成功后页面提示因子版本已发布，并显示可用于创建指标的版本 ID。

## 9. 常见问题

### 9.1 TOTAL_COST 在因子字段列表中没有“位于连续范围”

按顺序检查：

1. 值集版本是否已经发布；
2. 值集匹配模式是否为 `CONTINUOUS`；
3. 值集值类型是否为 `DECIMAL`；
4. `TOTAL_COST` 是否成功绑定该值集；
5. 在因子编辑器中重新选择数据域和语义表，或刷新页面，以重新读取字段绑定信息。

### 9.2 连续值集详情显示为空或没有值项

这是正常行为。连续值集本来就不应有枚举值项；应查看“连续值规范”区域，而不是寻找值项表。

### 9.3 试算任务已经成功，但页面没有显示结果

点击“刷新状态”或再次点击“试算并查看结果”。若仍为空，请检查后端结果接口返回是否包含 `batchStatus=SUCCEEDED` 以及 `targets/resultSets/results` 内容，并结合页面显示的任务 ID、批次 ID 和接口 traceId 排查。

### 9.4 发布按钮不可用

当前页面需要先完成编译，并完成一次成功试算和结果读取后才能发布。先检查“编译校验通过”“试算结果已读取”和质量状态是否正常。

### 9.5 因子页面找不到本次新建的数据域

因子页面只列出已发布数据域，而当前前端尚未提供数据域校验发布入口。确认数据域编码确实为 `TEST_CONT_COST_20260827_01` 后，请管理员或后端完成发布，再刷新因子创建页。不要为了绕过发布步骤而选择已有数据域，否则会重新使用既有语义字段和绑定，失去数据隔离意义。

### 9.6 绑定窗口显示该字段已经绑定值集

本手册新建的 `TOTAL_COST` 在首次绑定前应为未绑定状态。若窗口显示已有绑定，通常是进入了旧数据域、旧语义表，或 `TEST_20260827_01` 已被他人使用。关闭窗口并逐级核对数据域编码、语义表编码、字段业务名称和来源字段；不要点击确认覆盖。必要时将测试序号改为 `02` 并重新建立本次对象。
