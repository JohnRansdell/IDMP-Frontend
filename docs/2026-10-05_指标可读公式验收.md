# 指标详情可读公式验收

## 实现

- 后端 `GET /api/v1/indicator-versions/{id}` 新增 `formulaDefinition`，包含可读计算表达式、展示表达式、中文规则、引用因子和异常说明。
- 普通创建和 SQL 导入指标都从已保存的公式 AST 生成，使用实际引用的因子名称，不根据指标名或 SQL 注释猜测。
- 详情主区域用紧凑的分数排版展示简单比例公式，保留完整因子名称和实际展示倍率；复杂公式保留后端可读表达式，不猜测分子、分母。
- 默认只展示简短的除零、精度说明；“查看完整定义”只保留原始 JSON，默认折叠，不再展示规则与引用因子列表。
- 因子名称沿用公式正文颜色，去掉链接下划线，仅在悬停、键盘聚焦时提示可点击；原始 JSON 复用现有语法高亮组件，字段名与不同类型的值分别着色，长行在预览内部滚动。
- 公式中的因子名称可点击，跳转到现有 `/factor/edit/{factorId}?factorVersionId={versionId}` 编辑页，读取公式实际引用版本而非最新草稿。分数式、复杂表达式及同名因子的版本消歧均支持点击，未知引用不猜测链接。独立只读详情页已移除。
- 选择版本时读该版本公式，URL 支持 `versionId` / `indicatorVersionId` 指定版本；乱序响应不能覆盖最新选择，加载和失败状态不显示上一版公式。
- 不修改已保存计算定义、因子或正式结果，不触发编译和重算；复用版本详情已读取的因子元数据，无额外名称查询。
