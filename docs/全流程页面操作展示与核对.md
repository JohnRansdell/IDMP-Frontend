# 第 22 章枚举值集过滤全流程页面操作展示与核对

更新时间：2026-08-13  
适用前端：分支 `L`  
接口基线：`IDMP 当前实现接口文档与测试样例（基于方案 revision 1036）0813.md`  
演示主题：真实源值 `1/2/9` → 标准性别值集 → 男性出院病案因子 → 男性出院病案占比指标 → 自动回补 → 分析、下钻和因子追溯

## 1. 文档用途与本次结论

本文既是演示人员可以照着逐项点击的操作脚本，也是当前前端与第 22 章接口能力的核对记录。演示应当证明：

1. 管理员不需要猜测物理值 `1`、`2`、`9` 的业务含义。
2. 值集统一表达为“男、女、未知”，因子只保存标准值项编码 `MALE`，不直接依赖某一来源系统的 `1`。
3. 每个物理字段映射各自维护源值转换规则；以后接入另一个来源字段 `1/2/0` 时，只需把 `0` 映射到同一个 `UNKNOWN`。
4. 因子筛选同时包含统计周期和枚举值集条件，指标公式引用已发布的分子、分母因子版本。
5. 指标发布后，必须等正式结果回补成功，才能把分析页和下钻页作为验收结果。

当前前端已能呈现上述核心闭环。连续数值字段的 `GT/GTE/LT/LTE/BETWEEN` 固定值过滤仍未开放；本样例只验证日期周期和枚举值集过滤。

## 9. 多物理字段统一值集的正确操作

假设第二个来源表的性别字段取值为 `1/2/0`，目标不是再建一套“男、女、未知”，而是重复字段映射和标准化步骤：

1. 在第二个来源表对应的语义表中，将其性别物理字段映射为性别维度语义字段。
2. 给该语义字段绑定同一个已发布值集 `DEMO_PATIENT_SEX_VS_20260813_01`。
3. 点击该物理字段映射的“标准化”。
4. 配置 `1 → MALE`、`2 → FEMALE`、`0 → UNKNOWN`。
5. 预览未匹配为 0 后校验并发布。

由此，两套物理编码分别保留各自的转换规则，但因子筛选统一选择标准项 `MALE/FEMALE/UNKNOWN`。当前接口的转换规则挂在 `sourceFieldMappingId` 上，正好表达“同一个业务语义、多个来源物理字段、每个来源各自映射”。

## 10. 创建男性出院病案分子因子

### 10.1 基础和取数范围

1. 左侧点击“因子管理”。
2. 点击“创建因子”。
3. 在“1 基础信息”输入：
   - 因子编码：`DEMO_MALE_DISCHARGE_20260813_01`
   - 因子名称：`男性出院病案人次（演示）`
   - 业务分类：`医疗质量`
   - 说明：`统计指定周期内标准性别为男性的出院病案记录数`
4. 在“2 计算口径配置”选择：
   - 数据域：`枚举值集过滤全流程演示（DEMO_ENUM_DRILL_20260813_01）`
   - 语义表：`住院出院病案演示表（DEMO_INPATIENT_DISCHARGE）`
5. 确认“统计周期字段”显示 `出院时间（OUT_TIME）`。

### 10.2 统计方式

1. 在“3 统计方式”选择“记录计数”。
2. “计数字段”保持为空，表示 `COUNT(*)`。
3. “分组维度”保持为空，表示统计总体，不按性别拆行。

### 10.3 添加时间和值集过滤

1. 在“4 筛选范围”选择“显式筛选条件”。
2. 点击“添加筛选条件”。
3. 第一行字段选择 `出院时间（OUT_TIME）`。
4. 判断方式选择或自动显示“在试算周期内”。值由下方试算周期传入，不填写固定时间。
5. 再点击“+ 添加筛选条件”。
6. 第二行字段选择 `患者性别（PATIENT_SEX）`。
7. 判断方式选择或自动显示“属于标准值”。
8. 目标值选择 `男（MALE）`，不要输入物理值 `1`。
9. 点击“查看技术配置”，确认关键结构为：

```json
{
  "filters": {
    "nodeType": "AND",
    "children": [
      {"fieldCode":"OUT_TIME","operator":"BETWEEN","parameter":"period"},
      {"fieldCode":"PATIENT_SEX","operator":"IN_VALUE_SET","itemCodes":["MALE"]}
    ]
  },
  "aggregation": {"function":"COUNT"},
  "groupBy": []
}
```

页面生成的 `IN_VALUE_SET` 可以直接携带 `itemCodes`；是否同时出现命名参数不影响本样例的标准值含义，以后端编译结果为准。

### 10.4 保存、编译、试算、发布

1. 点击“保存草稿并继续”。
2. 记录页面显示的因子 ID 和版本 ID。
3. 点击“编译并校验”。
4. 编译通过后，在页面底部“本次试算周期”选择：
   - 开始：`2026-01-01 00:00:00`
   - 结束：`2026-02-01 00:00:00`
5. 点击试算按钮。
6. 若任务仍为 QUEUED/RUNNING，点击“刷新状态”；完成后查看试算结果。
7. 确认结果大于 0、质量状态正常后点击“发布因子版本”。

预期结果：工作流步骤依次完成“保存草稿 → 编译校验 → 试算完成 → 版本发布”。

   - 说明：`统计指定周期内全部出院病案记录数，作为男性占比的分母`
3. 数据域、语义表、统计方式与分子相同：记录计数、计数字段为空、分组维度为空。
4. 筛选范围选择“显式筛选条件”。
5. 只添加一条：`OUT_TIME` → “在试算周期内”。**不要添加性别条件**。
6. 保存、编译。
7. 使用相同试算周期 `2026-01-01 00:00:00` 至 `2026-02-01 00:00:00` 发起试算。
8. 确认分母结果大于或等于分子结果。
9. 点击“发布因子版本”，记录分母因子版本 ID。

验收关系：`0 < 男性分子 ≤ 全部分母`。如果分子大于分母，优先检查两个因子的时间窗口、语义表和分母过滤条件是否一致。

## 12. 创建男性出院病案占比指标

### 12.1 基础信息与版本

1. 左侧点击“指标管理”。
2. 点击“创建指标”。
3. 在“1 基础与版本”填写：
   - 指标编码：`DEMO_MALE_DISCHARGE_RATIO_20260813_01`
   - 指标名称：`男性出院病案占比（演示）`
   - 指标简称：`男性占比`
   - 指标分类：一级“医疗质量”，二级“质量安全”
   - 指标属性：`定量`
   - 计量单位：`百分比（%）`
   - 指标导向：`监测比较`
   - 统计周期：`月度`
   - 指标定义：`指定统计周期内男性出院病案人次占全部出院病案人次的比例`
   - 指标意义：`观察出院病案性别构成，并验证枚举值集标准化后的统一筛选能力`
   - 数据来源：勾选当前表单中与住院病案对应的来源项。
   - 政策文件来源：选择本次演示采用的政策来源；若该字段为必填，至少勾选一项。
4. “指标结果下钻路径”选择：
   - 路径编码：`组织下钻（ORGANIZATION）`
   - 最大层级：`出院科室（OUT_DEPT）`
5. 点击“保存并进入公式配置”。该按钮会先保存稳定指标，再创建首个草稿版本。

预期结果：页面切换到“2 公式与试算”，顶部显示指标 ID 和版本 ID。

### 12.2 配置公式

1. “计算模式”选择“简单比率型”。
2. 在“可用因子”搜索 `DEMO_MALE_DISCHARGE_20260813_01`。
3. 点击该因子卡片“添加”，将它加入分子；如果当前焦点不明确，拖到“分子（NUMERATOR）”槽位。
4. 搜索 `DEMO_ALL_DISCHARGE_20260813_01`。
5. 将它加入“分母（DENOMINATOR）”槽位。
6. 核对公式预览：`男性出院病案人次 ÷ 全部出院病案人次 × 100%`。
7. 点击“保存公式”。
8. 点击“公式校验”。
9. 校验通过后点击“发起试算”。
10. 任务完成后点击“查看结果”。
11. 检查结果在 `0%` 到 `100%` 之间，并与“分子 ÷ 分母 × 100%”一致。
12. 点击“发布指标版本”。

预期结果：指标版本变为已发布；发布结果中返回的指标 ID、版本 ID 要记录到演示记录表。

## 13. 等待自动回补并核对计算状态

发布成功不等于分析结果已经生成。第 22 章真实链路发布后共生成 17 个正式计算批次，最终全部 SUCCEEDED。

### 13.1 页面可做的核对

1. 在指标发布反馈或网络响应中记录 `taskId`、`batchId`；若只返回版本 ID，则后端运维侧需按 `ownerVersionId` 查询正式回补批次。
2. 左侧点击“计算任务”。
3. 有 `taskId` 时，在“异步任务 ID”输入完整 ID，点击“查询任务”。
4. 有 `batchId` 时，在“计算批次 ID”输入完整 ID，点击“查询批次”。
5. 状态未结束时点击右上角“刷新当前状态”。
6. 只有状态为 SUCCEEDED、目标成功数符合预期且失败数为 0，才进入分析验收。

### 13.2 当前页面边界

计算任务中心支持按已知任务 ID、批次 ID 查询，也支持手工创建单个计算批次；当前没有按指标版本自动列出全部 17 个回补批次的聚合视图。因此，“全部回补批次均成功”仍需结合发布响应、后端任务列表或运维查询确认，不能只凭指标发布成功提示判断。

## 14. 指标分析、排名和下钻验收

### 14.1 打开真实分析结果

1. 左侧点击“指标分析”。
2. 页面右上角“请选择指标”中搜索 `男性出院病案占比` 或完整指标编码。
3. 选择目标指标，点击“查看分析”。
4. 核对页头：指标版本、结果批次、数据水位和更新时间均来自目标对象。
5. 核对核心卡片：当前指标值、分子、分母与试算/正式结果的数量级一致。

如果列表里没有新指标：先确认指标已发布并完成正式回补；分析列表不是草稿指标目录。

### 14.2 趋势分析

1. 点击“趋势分析”。
2. 分别点击页面周期选项，核对月度、季度、年度切换。
3. 展开“查看趋势数据表”，核对图表与表格使用相同的周期和值。

### 14.3 科室排名

1. 点击“科室排名”。
2. 确认状态标识为“后端维度数据”；若显示“演示数据”，不能作为真实验收证据。
3. 找到一个有结果的科室，点击“查看明细”。

### 14.4 下钻分析

1. 点击“下钻分析”。
2. 若存在已激活结果，页面显示 `DrillExplorer`；依次选择医院、出院科室等组织层级。
3. 对病种路径，依次进入全部病种、单病种、病例层级。
4. 进入患者或业务明细前，按页面要求填写访问原因；完成后检查审计记录。
5. 在因子追溯区域核对：
   - 分子指向“男性出院病案人次”正式因子结果。
   - 分母指向“全部出院病案人次”正式因子结果。
   - 两个引用的版本 ID 与指标公式保存时一致。

如果页面显示“当前指标尚无可下钻的已激活结果”，先回到第 13 节确认回补；这不是前端渲染错误。

## 15. 一次完整演示的口述顺序

演示人员可按下面的话术串联页面：

## 18. 最终验收判定

满足以下条件才能判定“完整链路通过”：

- 值集已发布且成功绑定 `PATIENT_SEX`。
- 所有性别源值均有转换规则，预览未匹配数为 0。
- 分子 DSL 含 `OUT_TIME BETWEEN period` 和 `PATIENT_SEX IN_VALUE_SET [MALE]`。
- 分母 DSL 仅含相同的时间条件，不含性别过滤。
- 两个因子均编译、试算并发布成功，且 `0 < 分子 ≤ 分母`。
- 指标公式引用的正是本次两个发布因子版本。
- 指标试算为合理百分比并发布成功。
- 正式回补批次成功，分析页显示后端正式结果而非演示数据。
- 组织、病种/病例和因子追溯至少各验证一条有效路径。

若前七项通过、回补或下钻未完成，应记录为“计算链路通过，正式结果/下钻待验证”，不能写成“全流程通过”。
