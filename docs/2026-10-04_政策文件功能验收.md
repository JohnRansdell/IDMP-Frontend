# 政策文件上传、秒传、关联与查看验收

## 分支与设计依据

- 前端：`feature/policy-documents`，从远程 `main` 建立。
- 后端：`feature/policy-documents`，从远程 `master` 建立；独立工作目录 `D:\idmp-policy-documents`，未修改 `D:\idmp` 中原有的自定义下钻工作。
- 依据飞书《医疗质量指标数据管理平台(IDMP)_系统架构与详细设计》revision 1047，第 2.12 节。
- 前端入口：`http://127.0.0.1:5173/policies`。
- 接口联调：`http://8.137.157.152/api/v1`。通过 `lab-server` 拉取远程分支后执行 `./start.sh restart`，未验证外部 actuator 路由。

## 已实现的操作

1. 政策信息创建、编辑、检索、分页。
2. 上传附件，保存草稿版本，发布和归档版本。
3. 浏览器分块计算 SHA-256；命中已由服务端验证且仍可用的文件时不上传文件内容。首次上传由后端重新计算 SHA-256 并验证格式和内容。
4. PDF、UTF-8 TXT 站内查看；DOCX 下载查看。不把对象存储密钥或公开存储地址交给浏览器。
5. 政策版本之间建立引用、替代、补充、修订关系。
6. 已发布指标详情按政策名称或编码选择已发布政策版本，保存引用用途、出处和原文，并从指标详情查看附件；可作废引用。

## 存储部署与已知限制

- 服务器已安装并运行单机 MinIO，仅监听本机 9000/9001；数据保存在 `/home/tjg/idmp/.policy-storage/data`。
- 私有密钥由安装脚本随机生成，保存在 `.policy-storage/storage.env`，不提交 Git、不打印。
- API 启动脚本自动读取存储配置，并对已安装 MinIO 做进程身份与健康检查；系统 curl 检查隔离 Conda 动态库配置。
- 当前 Nginx 没有配置 `client_max_body_size`，默认上限 1 MiB。当前账号无法修改 root 配置，因此后端有效上限设为 **1000000 字节**，前端读取相同上限，避免允许选择后再被网关拒绝。
- 应用支持可配置的 50 MiB 上限。提升服务器上限需要管理员设置 Nginx `client_max_body_size 51m;` 并重载，再将私有配置 `IDMP_POLICY_MAX_BYTES` 改成 `52428800` 后重启 API。
- 单机 MinIO 已持久化但不是生产多节点高可用部署；需另行纳入机器重启编排与数据备份。
- 启用认证时文件读取沿用平台权限过滤器；本次联调没有覆盖生产角色全组合权限验收。
- 暂不自动删除未绑定文件；归档政策版本不删除共享附件。文本预览超过 1 MiB 会提示下载完整文件。
