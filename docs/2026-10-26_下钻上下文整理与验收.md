# 下钻上下文整理与验收

## 结论

前端下钻请求与成员身份处理已收敛。后端接口、计算 SQL、权限策略、正式结果均未修改，也未重算历史数据。

单元/组件测试与生产构建通过；看板真实下钻 48 项检查通过。新增排名浏览器测试保留一个失败项：三月转科比例的排名分母与正式结果不一致。不能据此宣称全链路数值验收全部通过。

## 实现边界

- `src/idmp/features/analysis/drillContext.js`：统一请求构造、成员编码字段、下一层父级键、名称与编码分离，以及版本/快照/路径/层级/周期响应核对。
- `src/idmp/api/adapters/drill.js`：集中旧语义字段名、旧内置层级字段、旧组织投影字段及路径根结果 ID 的兼容。
- `DrillExplorer.vue`、`backendChartDrill.js`、`departmentRanking.js`：都使用同一个请求构造入口，不再分别拼装快照、筛选和分页参数。
- 科室排名跳转保留行自身的快照和版本。行没有快照且行结果 ID 与响应根结果 ID 不同时，不能借用根快照。
- 下钻表格补传原先未使用的 `snapshotId`。切换另一条路径时，不继续发送原路径的快照。
- 版本 ID 不作为后端不支持的请求字段发送；用于核对返回上下文。区间下钻保持显式 `periodRange` 的排他结束日，正式结果的周期仅用于响应核对，不自动转为区间汇总。
- 删除页面和图表中重复的父级字段映射、根结果定位；配置字段优先于历史默认字段，不根据名称猜测业务字段。

## 成员身份规则

优先使用配置的 `memberKeyFieldCode`，其次使用 `dimensionFieldCode`；旧语义字段别名只在适配层展开。

只有路径配置明确标识为显示名称、且区别于身份字段时，名称才不作为导航键。已有身份编码时去掉冗余名称条件；只有名称没有编码时提示重新选择成员，不静默放宽筛选。不按 `_NAME` 后缀批量删除字段，作为真实身份字段的名称和其他病种筛选照常保留。

旧配置缺少字段绑定时仍允许既有内置路径协议；不能借此次整理删除所有历史支持。图表的 500 条绘图上限、分页完整性校验和后端权限判断不变。
