### P1 / SYS-001：因子模板尚未适配物理表 DSL

**修复进展（2026-10-03）：已修复、部署并完成真实复验。**后端 `master` 提交 `33179d1` 已推送；服务器先 `git pull --ff-only origin master`，再执行 `./start.sh restart`。API PID `455342`、Worker PID `455577`，均已就绪。

模板校验改为复用普通因子的无写入编译校验，接受数据域内已发布映射的物理表、字段及受治理 JOIN，继续禁止原始 SQL。参数无默认值时，仅延迟相关参数值检查；实例化填值后完整校验，再创建因子，非法字段不会留下因子草稿。缺少物理表的历史模板需要创建新版本补齐物理表，不自动猜测来源。

## 8. 已识别边界，暂不作为核心阻断缺陷

1. `ROUND(n * 100.0 / NULLIF(d,0),2)` 解析 preview.valid=true，但 formula=null，混合导入不能提取公式；普通 `/d` 可以。属于公式提取支持范围及诊断质量问题，不能宣称任意 SQL 比率表达式都支持。
2. 不传 `Idempotency-Key` 时，同 SQL 按 hash 复用旧会话，abandon 后再提交仍可能返回 ABANDONED。前端通常使用新的 key，本轮记作接口使用边界，不称标准前端必现。
3. 绩效考核、质量安全综合看板的组件缺少数据源绑定；各组件返回 ERROR，其他看板正常。属于历史配置问题，非计算引擎整体失败。
4. 映射组和 REJECTED 映射会阻止被引用指标删除；本轮未发现映射组停用或删除接口。不能仅凭清理失败判定引用校验本身错误，需要确认配置资源退出规则。
