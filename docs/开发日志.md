## 后续执行步骤

每完成一个功能，建议按以下顺序操作：

```bash
npm run build
git status
git diff --stat
git add .
git commit -m "feat: 功能说明"
git push
```

如果功能存在后端联调内容，应在本日志中写清楚“点击哪里、输入什么、接口返回什么、页面如何证明已经接入”。
