# 指标分析展示层整理

## 范围

仅整理前端指标分析页的展示职责。不修改后端接口、计算口径、指标配置或正式结果；不调整原有排名周期和下钻入口选择规则。

## 职责边界

| 模块 | 职责 |
| --- | --- |
| `IndicatorAnalysis.vue` | 查询条件、版本元数据、请求协调、路由、下钻入口、诊断和 PDF 导出 |
| `AnalysisOverview.vue` | 核心指标、摘要、状态和响应式布局 |
| `AnalysisTrend.vue` | 月份与粒度控件、高级筛选、趋势图、数据表、加载与重试 |
| `AnalysisDepartmentRanking.vue` | 排名周期控件、排名表、状态和查看明细操作 |
| `overviewPresentation.js` | 概览展示模型、单位和目标值 |
| `trendPresentation.js` | 趋势坐标、目标线和表格行 |
| `departmentRanking.js` | 科室结果适配、排名展示行及下钻上下文 |

展示组件不发业务请求，不解析路由，不从其他结果补值。筛选通过事件回传；修改高级筛选时创建新对象，不直接修改父级传入的对象。页面与 PDF 使用同一份概览、趋势和排名展示模型。

组件样式随模板迁移，删除原页面中没有模板引用的场景比较样式。保留原有桌面、平板和窄屏布局。

## 验证

- `npm test`：1002 项通过，其中新增 9 组展示组件测试，覆盖零值与空值、查询状态、结果来源、百分比精度、目标线、筛选事件、排名排序及下钻上下文。
- `npm run build:prod -- --outDir .tmp/presentation-components-dist`：通过。
- `test/result-presentation.live.mjs`：4 组真实数值与图表像素验证通过。死亡率 1/429 显示 0.23%，0/679 显示 0.00%，跨季度多科室转科比例 13/2490 显示 0.52%，静态值为 940333.88。图表坐标保留未舍入精度，单点及目标线实际绘制。
- `test/analysis-request-state.live.mjs`：8 组真实浏览器场景通过，覆盖慢响应、快速切换月份、失败重试、无数据、按需加载、排名点击医生下钻、切换指标及返回、未进入排名页签时导出 PDF。验证排名行的结果 ID、周期、路径和科室上下文与下钻请求一致。网络故障及迟到响应通过浏览器拦截制造，正常数据来自实际后端。
- `test/analysis-presentation-layout.live.mjs`：1440、768、390 像素宽度通过，检查概览、筛选控件和展示区无横向溢出，并留存三个区域的截图。
- 本地证据位于 `.tmp/展示层整理20261026/`；凭据、截图和导出文件不提交。

## 已知边界

三月转科比例排名分母 902 与正式结果、医生下钻汇总及源表去重 891 的后端差异不在本次整理范围内。本次验收不代表该差异已修复，也不代表系统全部功能无缺陷。
