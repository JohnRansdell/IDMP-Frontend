# 指标分析请求状态整理

## 范围

仅整理前端指标分析的请求生命周期，沿用现有接口和统计口径，不修改后端、指标配置或正式结果。

## 职责划分

| 模块 | 职责 | 重新加载条件 |
| --- | --- | --- |
| 页面初始化 | 版本、路径、因子元数据、科室名称、可用周期 | 指标、版本或外部查询上下文变化 |
| 总览 | 总览及诊断信息；不附带重复趋势或时间指标的排名结果 | 页面初始化 |
| 报告期汇总 | 月季年读取正式汇总，自定义区间即时查询 | 用户查询报告期或初始化显式报告期 |
| 趋势 | 只请求 TREND；独立处理加载、无数据、失败和重试 | 趋势月份、粒度或组合筛选变化 |
| 科室排名 | 独立周期选择及当前上下文内的结果缓存 | 首次进入排名或导出，以及排名周期变化 |
| 下钻 | 独立周期、结果、路径、父级成员、分页和因子追溯 | 首次进入下钻或下钻条件变化 |

共享的请求作用域负责 AbortController 和响应有效性校验。接口支持取消时终止传输；即使异步工作不支持取消，也不能把旧响应写回当前状态。结果采用浅层响应式引用，避免给整个结果树创建响应式代理。

科室字典是共享缓存，不取消其他页面可能正在复用的字典请求，只失效当前页面的消费者。

## 移除的耦合

- 趋势条件变化不再调用整页初始化；页面内部同步 URL 不再被路由监听器当作外部导航重新加载。
- 无数据或失败的趋势不再改查无筛选周期，也不再借用总览趋势或把趋势响应替换成主结果。
- 排名不再借用主结果中的排名充当独立周期结果。
- 离开页签会取消未完成的排名、下钻请求；返回时恢复原周期和入口上下文。已经完成的结果保留。
- 下钻按实际配置内容识别变化，相同内容的新对象不会导致重查；结果和筛选同时更新时只发一次请求。
- 切换指标、卸载或停用页面时，旧请求不能回填数据或错误。静态指标不发送无意义的趋势请求。
- PDF 导出按需读取尚未加载的排名；等待期间查询条件发生变化则中止导出，避免报告混用上下文。
