复杂费用指标功能验收依据（测试文件）
批次：20261027_CX01。
指标名称：每百出院人次非药非耗材费用。
用途：验收原子因子、嵌套公式、舍入、正式计算、组织下钻及版本追溯功能。
该名称和公式为本次软件功能验收口径，不代表已确认的法定医疗质量指标。

四个因子全部来自 vmq_basicinformationba，按出院时间 out_date 限定同一周期。
T = SUM(total_cost)，住院总费用。
D = SUM(drug_cost)，药品费用。
M = SUM(material_cost)，耗材费用。
N = COUNT(DISTINCT VISIT_ID)，出院住院人次，不等于跨住院记录去重的自然人数。
指标 = ROUND(((T - (D + M)) / N) * 100, 2)。
分母为零时返回空值并呈现对应可用性状态，不伪造为正常零费用。
按元展示，每百人次的含义写在名称及定义中；整体展示乘数为1。
只在最终值舍入，中间费用和除法不提前舍入。

首轮周期：2026-01-01 00:00:00（含）至2026-02-01 00:00:00（不含）。
组织字段：出院科室 out_dept_code，医生 attending_doctor。
先用源库只读SQL记录当日四因子及最终结果，后续试算和正式结果逐项核对。
