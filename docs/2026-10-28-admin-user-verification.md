# 管理员创建用户验收

系统管理用户列表增加“创建用户”。复用已有 `POST /system/users`、`GET /system/depts` 与角色接口，不新增后端身份体系。

创建时填写工号、姓名、初始密码及确认密码，选择现有可用角色和科室；支持联系方式、备注和启用状态。普通角色须指定所属科室，管理员可不指定。创建成功自动刷新列表。关闭或成功提交后清空密码，提交过程中禁止重复提交和关闭。

仅系统管理员显示入口。后端已有实时管理员权限校验、BCrypt 密码保存、工号唯一及科室角色引用校验，本次不修改后端接口。

## 验收结果

- 前端全量 1113 项通过，生产构建通过。
- 三组真实页面创建：科室分析员、系统管理员、停用审计员；逐项核对工号、姓名、角色、科室和启用状态的持久化结果。
- 启用账户登录成功并拥有指定角色；科室用户创建接口返回 403；停用账号登录被拒绝；重复工号返回 409。
- 关闭弹窗重新打开无密码残留；桌面和 390px 手机弹窗未超出视口，无页面异常。
- 本次临时用户均已删除，不修改现有用户和角色权限。
