# 结果字段与展示整理

## 范围

分支：`feature/medical-sso-dashboard`。本轮仅修改前端，没有修改计算 SQL、汇总算法、正式批次或后端接口。

- `api/adapters/result.js` 集中处理指标值、分子、分母的协议别名；显式空值不再被旧别名覆盖。周期、状态、结果 ID 等信息原样保留，不重新推断计算状态。
- `features/shared/resultPresentation.js` 统一合法数值判断、单位、图表数值和展示格式。分析页、看板、下钻表格及图表使用同一入口，移除原有重复转换。
- 后端 `displayValue` 优先。唯一粒度的正式结果将展示文本随排序一起传递到表格、排名、标签和提示；聚合结果不借用某一行的展示值。
- 分析页已取得版本公式时，按公式的展示乘数、精度和舍入方式处理缺省展示；采用 decimal.js，与后端 30 位乘法精度及 Java 舍入模式对齐。`UNNECESSARY` 不能满足时不伪造数值。
- 图表保留未舍入的数值，格式化只用于文字。饼图下钻继续服从顶层绑定的指标值、分子或分母，不修改扇区度量。
- 真正的 0、缺失数值及不可计算结果不混淆；没有目标值时不画零目标线。有目标值时纵轴包含它，防止目标线被裁掉。
- 单点趋势不播放入场动画，避免展开数据表、调整尺寸后点停留在零缩放状态；点标签与表格使用相同展示格式。
- PDF 趋势表复用页面展示文本，不再另行拼接单位。

指标详情页展示指标定义而非运行结果，本轮没有为了复用格式化函数额外引入结果请求。

## 保留的边界

旧看板绑定数据中 `%` 表示已经换算的百分数，`PERCENT` 表示原始比率；分析和下钻接口的原始值则都是比率。这一转换明确保留在适配入口，不能直接删除或全局再次乘以 100。

只有已取得公式配置的页面使用配置化展示乘数；没有配置的消费者优先使用后端展示文本，数值坐标依据接口单位。不从舍入后的文字反推原始数据，也不增加完整分析请求。

## 验证

- 全量自动化测试 983 项通过，生产构建通过。
- 质量安全看板：管理员与本科室用户，三个组件，单月、一至三月、二至四月共 18 组实际下钻场景，48 项断言通过。检查请求范围、下钻上下文以及图形使用的原始数值。
- 一月呼吸科死亡率：分子 1、分母 429，展示 0.23%，图表保留后端未舍入比率换算后的坐标。
- 一月零值科室：0/679，展示 0.00%，不当作缺失数据。
- 跨季度多科室转科比例：13/2490，展示 0.52%；区间汇总与逐月趋势分别校验，不用某个月的值冒充区间结果。
- 静态结果：940333.88，仍显示静态结果，不显示虚构的趋势周期。
- 浏览器检查了实际展开的趋势表格、运行时异常、截图及数据点和目标线的画布像素。

复现入口：`test/result-presentation.live.mjs`、`test/dashboard-range-click.live.mjs`。本地原始响应和截图位于忽略目录 `.tmp/结果展示整理20261026`，不提交账号凭据或令牌。
