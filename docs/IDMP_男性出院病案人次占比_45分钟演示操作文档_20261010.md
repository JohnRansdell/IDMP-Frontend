# 男性出院病案人次占比：45 分钟现场操作演示

> 2026-10-11 按当前前端与演示环境核对。本场从现有数据域、值集、标准化规则及已发布因子开始；**在台上新建占比指标，并亲手配置自定义下钻路径和逐因子字段绑定**，然后创建演示口径文件及指标引用。数据域、值集、原子因子与内置科室下钻在旧演示中已经展示，本场不重复创建。

**本次展示顺序：**复合因子与依赖 → 现场创建指标、配置自定义下钻路径及逐因子字段绑定 → 看计算目标 DAG 和可读公式 → 正式分析与 PDF → 政策文件上传、版本发布、站内查看和指标引用。

3. 本场只用下表对象。搜索后按**编码和版本 ID**核对，避开名称相似的旧演示对象。

**数值检查点：**2026 年 4 月 M=122、A=291、A−M=169、M÷A=41.92%。现场数据若有更新，以同周期同版本的回显为准，并核对 M≤A、A−M 与 M÷A 的关系。现场新建对象的 ID 不能预填，以下步骤均使用页面刚返回的实际 ID。

## 3—9 分钟：复合因子与依赖

1. 点“因子管理”，按编码搜索 **F_NONMALE_DISCHARGE_D1011B**，打开编辑页。确认页头版本 **102027642463116982**、状态“已发布”。在“复合因子”配置中向观众指出根节点“减”：左侧引用“全部出院病案人次1011”版本 **102027642463116937**，右侧引用“男性出院病案人次1011”版本 **102027642463116910**。即 A−M；它没有被占比指标当作分子或分母。
2. 在“因子依赖关系”点击“刷新”，保持“上游依赖”，应列出上述两个已发布版本。切到“下游影响”可查看当前版本的使用范围。这是新增的**版本级依赖**。
3. 在“运行参数与即时查询”选择 **2026-04-01 00:00:00—2026-05-01 00:00:00**，点“即时查询”，总体值应为 **169**。需要向观众复核时，分别打开上表的两个原子因子，以同周期即时查询，应为 122 和 291。推荐的几天短周期不能与整月数值比较。
4. 此处只展示“上游依赖”和 169 的真实值。DAG 放到现场指标完成计算之后一起讲，观众更容易把图与刚才点过的步骤对应起来。

## 9—24 分钟：现场新建指标并亲手配置新功能

1. 点“指标目录”→“新增指标”，进入“1 基础与版本”。照表填写；本场只创建一个新指标。若编码或名称被前一场使用，两者末尾同时加唯一数字后缀，后续均搜索页面保存后的**实际编码**。

   | 页面字段 | 直接填写或选择 |
   | --- | --- |
   | 指标编码 | I_MALE_RATE_LIVE_20261011 |
   | 指标名称 | 男性出院病案人次占比现场演示 20261011 |
   | 指标简称 | 男性出院占比 |
   | 指标分类 | 医疗质量 → 功能定位 → 住院服务 |
   | 指标属性、计量单位 | 定量；百分比（%） |
   | 指标导向、统计周期 | 监测比较；月度 |
   | 指标定义 | 统计期内标准化性别为 MALE 的出院病案记录数除以同期全部出院病案记录数，按百分比展示；一行计一病案人次。 |
   | 指标意义 | 展示出院病案的性别构成，仅用于系统功能演示。 |
   | 数据来源 | 勾选“病案” |

   点“保存并进入公式配置”。页面应切到“2 公式与试算”，页头显示后端返回的实际指标编码和主 ID；**立即记下这两个值**。这里完成的是指标基本资料，版本仍是“尚未创建”。

2. 在“计算模式”点“简单比率型”。在“可用因子”搜索 **F_MALE_DISCHARGE_D1011A**，核对已发布版本 **102027642463116910**，点该因子的“添加”，让它进入**分子槽**。再搜索 **F_ALL_DISCHARGE_D1011A**，核对版本 **102027642463116937**，用鼠标把因子卡片**拖入分母槽**；列表“添加”按钮只会加到分子，不能用于分母。确认公式预览是“男性 ÷ 全部 ×100%”，分母为零策略是“返回空值”。简单比率型已带 ×100%，不再手工乘一次。

3. **先点一次“预检下钻能力”**。页面“本次预检覆盖因子版本”应同时出现上述两个版本；这一步把两个因子可选的物理字段加载到页面。此时还没有自定义路径，“因子维度字段映射”区域可能尚未出现；下一步添加路径后就能选择字段。填写完还要重新预检。

4. 在“自定义下钻路径”点“添加路径”。在“路径名称”填 **全院到出院科室**，保持系统自动生成的根层级“全院”。它下面默认新增的业务层级四个框依次填写：**层级名称=出院科室；维度名称=OUT_DEPT_CODE；成员编码维度（可选）=OUT_DEPT_CODE；显示名称维度（可选）=OUT_DEPT_NAME**。路径代码由页面自动生成，**不要尝试自己填路径代码**。

5. 到“因子维度字段映射”，现在应有**男性因子**和**全部因子**两组，每组有两个下拉框。四个选择必须逐项完成：

   | 因子版本 | 逻辑维度 | 下拉选择的实际物理列 |
   | --- | --- | --- |
   | 102027642463116910 男性 | OUT_DEPT_CODE | vmq_basicinformationba.out_dept_code（base.out_dept_code） |
   | 102027642463116910 男性 | OUT_DEPT_NAME | vmq_basicinformationba.out_dept_name（base.out_dept_name） |
   | 102027642463116937 全部 | OUT_DEPT_CODE | vmq_basicinformationba.out_dept_code（base.out_dept_code） |
   | 102027642463116937 全部 | OUT_DEPT_NAME | vmq_basicinformationba.out_dept_name（base.out_dept_name） |

   **这四个绑定就是本次新增能力的现场操作。**两因子虽来自同一张表，系统仍分别保存字段映射；后续换成不同来源因子时，它们可以指向各自的物理列。

6. 在同一区域“组合粒度”的输入框填 **OUT_DEPT_CODE**，点旁边“新增维度”，确认下面出现 OUT_DEPT_CODE 标签。它让计算生成 BASE 基础目标，不能只配自定义路径而漏掉此项：在当前后端，缺 BASE 的旧版本曾出现“计算成功、正式分析却返回 409”的问题。

7. **第二次点“预检下钻能力”**。刚建的“全院到出院科室”一行应显示“支持，最深到出院科室”，覆盖版本仍是 102027642463116910 与 102027642463116937。该自定义路径的“启用”控件可能灰色，因为路径由配置直接启用，不必再勾一次。若预检显示字段缺失，回第 5 步从下拉重选真实列，再点预检；不跳过红色或“不支持”结果。

8. 滚到“公式与试算操作”，点 **“创建版本并保存公式”**。页面应出现“计算公式已保存”并给出新的**指标版本 ID**；记录它。然后点“公式校验”，等“公式校验通过”。在“本次试算周期”选 **2026-04-01 00:00:00—2026-05-01 00:00:00**，点“试算并查看结果”，等待异步任务结束并记录**试算批次 ID**。试算目标中 **BASE 是 24 行逐科室结果**；切到“月”或自定义路径“全院”目标，才应看到全院分子 **122**、分母 **291**、占比 **41.92%**。不要把 BASE 的第一行科室值误读成全院占比。

9. 点“发布指标版本”，等状态成为“已发布”。发布时系统可能自动开始历史回补；**发布成功只表示版本可用于正式计算，不代表 4 月正式结果已经生成**。先用本次试算批次演示下一节 DAG；分析页面的数据就绪后再导出 PDF。

## 24—29 分钟：读懂刚才那次计算的 DAG 和可读公式

**DAG 是“计算步骤依赖图”**：每个框是一个实际执行的步骤，连线表示后续步骤要用到前一步结果。它不是新的计算公式，也不是看板。本场有两个并列输入——男性因子 M=122、全部因子 A=291；两者完成后，公式节点计算 M÷A=41.92%，质量检查节点再检查结果。科室目标会按刚绑定的字段分别执行同样的步骤。复合因子 A−M 不在占比公式里，因此不会出现在本指标的 DAG。

1. 点“计算任务中心”，在“计算批次 ID”填第 8 步**现场记录的试算批次 ID**，点“查询批次”。确认批次成功，滚到“计算目标与节点”。“目标”就是同一指标按什么粒度算一次：例如 **BASE** 按 OUT_DEPT_CODE 分组，自定义路径的 **ROOT** 是全院，**OUT_DEPT** 是出院科室。
2. 展开 **BASE** 或 **DRILL:自定义路径代码:OUT_DEPT** 目标，沿线指出两个因子节点先完成，公式节点再计算比例，质量校验节点最后检查结果。点任一节点，右侧“计算节点详情”显示该节点的版本、状态、上游依赖；点击上游名称可回到对应节点。解释一句即可：“如果男性因子失败，依赖它的公式和质量检查就不能得到可信结果。”
3. 再回“指标目录”，按刚记录的**实际编码**打开新指标详情，选择本场刚发布的版本。“指标公式”应展示可读分式，鼠标悬停因子名称可见版本，点击可打开因子；“查看完整定义”才是技术 JSON。这样观众能把**可读公式（业务写法）**与**DAG（执行顺序）**对上。

## 29—35 分钟：生成正式结果、查看科室并导出 PDF

1. 回到本场指标编辑页“2 公式与试算”，试算周期保持 **2026-04-01 00:00:00—2026-05-01 00:00:00**。发布后点 **“生成正式结果并去指标分析”**：页面会优先读取已经回补的正式结果；如果尚无可用结果，会创建并等待本周期正式计算，完成后跳到“指标分析”。若按钮仍显示“正在生成”，等真实任务结束；不能拿试算结果冒充正式报告。
2. 在“指标分析”确认选中的是**刚新建的实际编码和刚发布的版本**。2026 年 4 月的正式分析应为 **41.92%**、分子 **122**、分母 **291**；科室对比应有 **24** 行。选“全院到出院科室”路径，找到“泌尿外科”，可核对编码 **22**、分子 **23**、分母 **35**、占比 **65.71%**。这次点击只验证自定义路径配置，点击科室的动作本身是旧功能。
3. 等趋势、科室及要展示的下钻表都加载完，点击页头“导出PDF”。打开下载文件，核对标题、**本场新版本 ID**、2026 年 4 月、41.92%、122、291 与已加载图表。PDF 固化当前报告，不会再次计算。若先在“报告期”选择日期并点“查询”，页面会切成“即时计算”；本段展示正式报告时，直接从已加载的正式结果导出。
## 35—43 分钟：政策文件上传、发布、查看和引用

1. 点“政策文件”→“新建政策文件”。弹窗填 **文件名称=男性出院病案占比现场口径说明 20261011；编码=POLICY_MALE_RATE_LIVE_20261011；类别=其他；发布机构=演示项目组；文号=DEMO-LIVE-20261011；说明=仅供 IDMP 技术演示，非正式医疗政策或临床评价标准**。若编码被前一场使用，在末尾加当天唯一后缀，后续按实际编码搜索。点“保存”，详情应打开；此时只有档案，没有已发布附件。
2. 在详情“文件版本”点“上传新版本”→“选择文件”，选开场的 **演示用男性出院病案占比口径说明.txt**。等“上传完成”或“秒传完成”；环境中已有同内容附件时秒传正常。**发布日期**选演示当天，**生效日期、失效日期留空**，点“保存草稿”。版本列表应新增 **V1 / 草稿**。点该行“查看文件”，站内应显示 TXT 正文的统计对象、分子、分母、计算方法；关闭预览。
3. 在同一 V1 行点“发布”，确认“发布后文件与日期不可修改”。状态应变为“已发布”；再次点“查看文件”确认可打开。讲解时称它为**演示口径说明**，不称正式医疗政策。这一段展示新增的附件上传、内容复用、版本与站内预览。
4. 回“指标目录”按第 9—24 分钟记录的**实际编码**打开本场新指标，选刚发布的**实际版本 ID**。在“政策依据”选择器搜索上一步政策文件的实际编码，选刚发布的 **V1**；“引用角色”选“参考依据”；“政策出处（可选）”填“演示口径说明：计算方法”；“政策原文（可选）”填“分子除以分母，按百分比展示；分母为零时不展示为 0%。”；点“添加”。表格应出现文件名与“参考依据”。点该行“查看”能再次打开 TXT；刷新详情后引用仍应存在。这是新增的**已发布指标版本关联已发布政策文件版本**，不会改写指标计算结果。
