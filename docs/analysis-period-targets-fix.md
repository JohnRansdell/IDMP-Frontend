# 指标分析周期与目标取数修复

## 原因与改动

- 以远程主分支 `3fd5e20` 为起点，在 `fix/analysis-period-targets` 修复；不修改指标配置，不重算正式结果。
- 分析概览不再默认附带组合粒度明细。排名与下钻周期发现显式请求 `TREND` 摘要，再对选定周期请求 `OVERVIEW,DEPARTMENT_COMPARISON,CALCULATION_TARGETS`；实际层级成员继续走现有下钻查询。发现周期时不再提前执行排名下钻。
- 仍保留版本、科室筛选、取消请求、缓存、旧响应隔离、排名与下钻的独立周期选择。选定周期缓存不能由跨周期摘要代替。
- 未请求维度明细时不再把空数组解释成“本期暂无结果”，改为展示配置状态。概览读取实际 API 的 `numeratorValue` / `denominatorValue`，保留旧展示模型别名及零值。
- 后端配套提交 `799f539` 已部署 lab-server：组合对比按当前概览周期读取，不将多个周期的明细合计误判为单周期超过 10000 行；没有放大上限或截断结果。
