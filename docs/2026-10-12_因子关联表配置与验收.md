# 因子关联表配置与验收

## 分支与范围

- 前端分支：`feature/inline-factor-table-relations`，从 `tat-dev` 创建。
- 非 SQL 原子因子编辑页的“关联数据表”支持现场创建关联关系。
- 后端未修改，复用已部署的物理表关系创建、校验、发布和查询接口。
- 原有未提交源码、测试文件及环境文件保留，不纳入此次功能。

## 配置流程

选择主表后添加关联表，在当前区域选择目标数据域、目标物理表、关联方式、关联关系和两侧物理字段。
支持多组关联字段；保存并使用时依次创建关系草稿、校验、发布，发布成功后将关系 ID 写入当前因子的 DSL。
关联区域提供两个互斥选项：“复用已有表关系”和“创建并使用新表关系”。前者只显示已有关系选择框，后者只显示新关系配置表单；切换选项会保留尚未提交的表单内容。
页面不要求填写内部关系编码或表绑定 ID。
界面展示物理字段，关系管理接口使用内部字段编码，因子的计算 DSL 继续使用物理字段。

## 边界

- 沿用普通因子最多两次 JOIN 的限制。
- 仅支持 INNER、LEFT 和从当前来源表出发的一对一、多对一关系。
- 不允许同一表绑定关联自身，关联键必须完整、两侧类型一致且不能重复选择。
- 后端关系校验检查配置与字段状态，不自动扫描源数据证明关联键唯一；关联关系需要按真实数据配置。
- 校验或发布失败可以继续使用原草稿；创建响应丢失后按本次生成的固定编码恢复草稿。
- 发布后的已有关系不直接修改，避免影响引用该关系的其他因子。
